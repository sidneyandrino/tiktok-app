Privacy Policy

Last updated: May 19, 2026

1. Overview

This application ("TikTok Integration App") is a private tool that uses the TikTok Content Posting API to publish video content on behalf of its authenticated owner. It is not a public-facing service and does not collect data from third parties.

2. Data We Access

When authorized by the user, this application accesses:

  • TikTok account identity (username, open_id) — solely to authenticate API requests
  • Video upload permissions — solely to post content on behalf of the authenticated user

3. Data We Do Not Collect

We do not collect, store, sell, or share any personal data. Access tokens obtained via OAuth are used exclusively during the active session for API communication and are not persisted in any database or third-party service.

4. Data Retention

No user data is retained beyond the scope of the active API session. No logs, analytics, or tracking mechanisms are implemented.

5. Third-Party Services

This application communicates exclusively with TikTok's official API endpoints (open.tiktokapis.com). No other third-party services receive user data.

6. User Rights

You may revoke this application's access to your TikTok account at any time via TikTok's app settings (Settings → Security → Apps and Sessions).
